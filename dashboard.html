How to change a price
  1. GitHub repo kholo jahan index.html hai.
  2. index.html par click karke pencil (✏️) / edit icon dabao.
  3. Jis package ka price change karna hai, us mein 2 jagah edit karni hongi:
    • <div class="price">$80</div> — yahan number badlo
    • Usi package ke WhatsApp link ke andar %2480 jaisa likha hai — 80 ko naya price se replace karo (yehi price WhatsApp message mein customer ko dikhega)
  4. Neeche scroll karke "Commit changes" dabao. Site 1–2 minute mein khud update ho jayegi (Vercel automatically deploy karta hai).
